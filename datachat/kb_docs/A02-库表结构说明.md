# mall_ads MySQL 库表结构说明
来源：export_ads_to_mysql.py 的 create_mysql_tables()

## 连接信息
- 主机：localhost（WSL2 Ubuntu 内 MySQL 8.0，端口 3306 映射 Windows 本地同样可达）
- Agent 只读账号：agent_ro / 123456，仅 SELECT 权限
- 库名：mall_ads，字符集 utf8mb4，引擎 InnoDB

## 表一 ads_trade_stats（交易日报表）
主键：dt（日期，格式 yyyy-MM-dd），一行代表一天

字段：
- dt              VARCHAR(20) 主键   日期
- gmv             DECIMAL(16,2)     当日GMV总成交额（含未支付）
- order_count     BIGINT            当日订单总数
- pay_user_count  BIGINT            当日支付成功的独立用户数
- avg_pay_amount  DECIMAL(16,2)     当日客单价：支付GMV / 支付订单数

数据范围：2026-08-19、2026-08-20、2026-08-21 共 3 天

## 表二 ads_repurchase_rate（复购率日报表）
主键：dt，一行代表一天

字段：
- dt                      VARCHAR(20) 主键   日期
- order_user_count        BIGINT             当日下单用户数
- repurchase_user_count   BIGINT             当日下单用户中的复购用户数（累计下单 2 天及以上）
- repurchase_rate         DECIMAL(10,4)      复购率 = repurchase_user_count / order_user_count

复购率定义：当日下单用户中，历史累计下单天数 大于等于 2 的用户占比（跨天复购口径）

## 表三 ads_user_rfm（RFM 用户分层表）
主键：(dt, user_id) 复合主键，每行代表某天对某用户的一次 RFM 画像快照

字段：
- dt          VARCHAR(20)    快照日期
- user_id     VARCHAR(64)    用户唯一ID
- r_score     INT            最近消费R分 1-5，越大越近
- f_score     INT            消费频次F分 1-5，越大越频繁
- m_score     INT            消费金额M分 1-5，越大越贵
- rfm_label   VARCHAR(32)    用户分层标签 8类之一

数据量：约 2824 行（每个 dt 约 900 加 用户）
标签枚举：重要价值用户、重要保持用户、重要发展用户、重要挽留用户、一般价值用户、一般保持用户、一般发展用户、一般挽留用户

## 典型查询写法
最近三天GMV：SELECT dt, gmv, order_count FROM ads_trade_stats WHERE dt 大于等于 '2026-08-19' ORDER BY dt
复购率趋势：SELECT dt, repurchase_rate, order_user_count FROM ads_repurchase_rate ORDER BY dt
某日RFM各分群人数：SELECT rfm_label, COUNT(*) AS cnt FROM ads_user_rfm WHERE dt='2026-08-21' GROUP BY rfm_label ORDER BY cnt DESC
