# 电商数仓 ADS 指标口径手册
来源：离线数仓项目面试问答手册 Q41-Q45

## ads_trade_stats（交易日报）主键 dt

### GMV（商品交易总额）
- 定义：指定日期的所有订单金额总和，包括未支付订单
- 公式：GMV = SUM(order_amount)
- 所属表字段：ads_trade_stats.gmv
- 说明：衡量平台交易规模的核心指标，口径包含待支付/已支付/已发货/已完成/已取消等全部状态订单的金额

### 订单数 order_count
- 定义：指定日期产生的订单总条数（去重计数）
- 公式：COUNT(DISTINCT order_id)
- 所属表字段：ads_trade_stats.order_count

### 支付用户数 pay_user_count
- 定义：指定日期至少产生一笔成功支付订单的不同用户数
- 公式：COUNT(DISTINCT user_id) WHERE order_status in ('已支付','已完成')
- 所属表字段：ads_trade_stats.pay_user_count

### 客单价 avg_pay_amount
- 定义：平均每笔成功支付订单的交易金额
- 公式：支付GMV / 支付订单数，等价于 ads_trade_stats.avg_pay_amount
- 所属表字段：ads_trade_stats.avg_pay_amount
- 注意：与GMV/订单总数不同，客单价仅分母取支付成功订单

## ads_repurchase_rate（复购率日报）主键 dt

### 复购率 repurchase_rate
- 定义：当日下单用户中，历史累计在 2 个及以上不同日期下过单的用户占比（跨天复购口径）
- 公式：复购率 = repurchase_user_count / order_user_count
- 所属表字段：ads_repurchase_rate.repurchase_rate，范围 0~1，存储 DECIMAL(10,4)

### 当日下单用户数 order_user_count
- 定义：dt 当日有下单行为（total_amount 大于 0）的不同 user_id 数量
- 所属表字段：ads_repurchase_rate.order_user_count

### 复购用户数 repurchase_user_count
- 定义：当日下单用户中，历史累计下单天数 大于等于 2 天（截止到 dt 当天）的用户数
- 所属表字段：ads_repurchase_rate.repurchase_user_count

为什么不用订单数大于等于2？因为同一天可能多笔订单，按订单数几乎所有人都是复购，指标失去意义；按不同天数才能体现真实的回访复购。

## ads_user_rfm（用户价值分层）主键 (dt, user_id)

### R 分 r_score（最近消费，5 档）
- 定义：用户最近一次消费距今天数（Recency），越小越好
- 打分：按升序 NTILE(5) 后反转：tile1=5，tile5=1。最近消费=高分

### F 分 f_score（消费频次，5 档）
- 定义：近 30 天内用户的消费天数（Frequency），越大越好
- 打分：按升序 NTILE(5)。消费多天=高分

### M 分 m_score（消费金额，5 档）
- 定义：近 30 天内用户的消费总金额（Monetary），越大越好
- 打分：按升序 NTILE(5)。消费高=高分

### 用户分群 rfm_label（8 类）
规则：R F M 任意一维 大于等于3 视为高，小于3 视为低

| R | F | M | 标签 rfm_label |
|---|---|---|---|
| 高 | 高 | 高 | 重要价值用户 |
| 低 | 高 | 高 | 重要保持用户 |
| 高 | 低 | 高 | 重要发展用户 |
| 低 | 低 | 高 | 重要挽留用户 |
| 高 | 高 | 低 | 一般价值用户 |
| 低 | 高 | 低 | 一般保持用户 |
| 高 | 低 | 低 | 一般发展用户 |
| 低 | 低 | 低 | 一般挽留用户 |
